Logo Tampering Detection - Dataset
==================================

images/     : 50 phone-style photographs of NORVIA-branded packaging.
              Some logos are genuine; some have been subtly altered.
              Files are numbered only. No labels are provided.

reference/  : 3 clean images of the genuine NORVIA logo under good conditions.

NORVIA is a fictional brand created for this exercise.
You may create additional data if useful - please explain what you did and why.
